# 新卡素材与卡面

从本机大厅进入「开发工作台 → 卡面摄影」。也可以直接打开 [重装部队摄影棚](http://127.0.0.1:4317/play/workbench?view=photo&model=heavy_minion_squad)。摄影使用网页对局的 Three.js 模型、阵营和动作资源。下面的命令在 V1 根目录运行。

## 选择素材

| 制卡环节 | 入口与产物 |
| --- | --- |
| 查原版加载图、模型、动画与纹理 | 在旧项目目录运行 `python3 tools/dev.py source packages --query Garen`，再用 `python3 tools/dev.py source inspect --package Garen --kind card-art` 查看候选路径。提取工具会记录源包及校验值。将有用的源件和清单放在本机该卡的素材目录。 |
| 试听待选音频 | 在旧项目目录运行 `python3 tools/dev.py audio --directory "/绝对路径/候选声音"`。V1 工作台的「音效试听」用于检查正式打包的事件和变体。 |
| 挑选候选模型 | 在摄影棚的「成员与动作」打开自包含 GLB，选动作、播放、定格。可把候选与正式成员摆在一起。GLB 由浏览器从本机读取，纹理和缓冲区需要嵌入文件。 |
| 检查正式素材 | 工作台「模型与动作」「特效预览」「音效试听」「实战观察」共用顶部对象选择器。正式资源的导入入口见 [模型](../battle/小兵与建筑模型.md)、[特效](../battle/特效系统.md)和[音频](../battle/音频系统规划.md)。 |

## 拍摄和复拍

1. 通过「选择对象」指定卡牌或衍生物。组合卡按部署定义带入成员。可添加、移除、切换红蓝方及适用的形态，并逐个调整动作、定格时间、朝向、位置和大小。「机位与光线 → 完整取景」可在大幅改变姿势或队形后重新框住所有成员。
2. 在画布上拖动环绕、滚轮推拉，或用滑块精调取景高度、角度和距离。可调灯光、背景色、透明背景和地面。点击「拍摄卡面 PNG」将纯画面以 308×560 下载到浏览器下载目录。打开「查看卡槽裁切」可对照卡池、详情和手牌组件中的成片。
3. 通过「成片与方案 → 保存方案」导出 JSON，并在当前浏览器保存这个对象最近一次构图。给不同构图的 PNG 和 JSON 配对命名，保留在该卡的素材目录。用「打开方案」恢复指定版本。「恢复已存方案」读取当前浏览器副本。含本地 GLB 的方案需重新选择原文件，模型文件本身由作者保存。

## 接入正式卡面

已有合适的原版加载图时可直接登记原图。选中的摄影图使用 PNG，并可附上对应方案。登记对象须已进入 V1 卡表或工作台衍生物目录。

```sh
python3 tools/card_art.py install heavy_minion_squad "/素材/重装部队/定稿.png" --kind photo --recipe "/素材/重装部队/构图.json"
python3 tools/card_art.py install sona "/素材/娑娜/原版加载图.png" --kind original --source "源包名及包内路径"
python3 tools/card_art.py verify heavy_minion_squad
```

`install` 更新 [V1 卡面登记](../../content/card_art.json)，记录来源、源文件 SHA-256 和运行图片。运行 WebP 使用内容哈希命名，保存在 `web/public/media/card-art/`，随图登记的方案保存在 `content/card-art-recipes/`。同一 ID 再次登记会切换正式卡面。目录导入器刷新旧站卡表时，V1 登记和摄影文件独立保留。具备 V1 正式规则且仅在 V1 建立的卡牌也保留其目录记录。

将登记、生成的 WebP 和附带方案一并纳入版本管理。通过前端构建和 Rust 宿主重新构建发布，两个卡表 API 与客户端就会读取新图。摄影操作仅生成本地候选文件。

## 检查实际显示

```sh
python3 tools/card_art.py verify
node web/tests/card-art.mjs heavy_minion_squad sand_soldier
```

第一条检查全卡池、特殊裁切和衍生图的文件及正式登记。第二条连接已启动的本机开发大厅，在 Chrome 中输出指定对象的裁切对照图，并为正式卡另存真实卡池与详情截图。对照图中的手牌使用战斗手牌组件。可用 `LOBBY_URL` 指定宿主，用 `CARD_ART_OUTPUT` 指定截图目录。省略 ID 会额外检查单体、混合编队、高建筑的拍摄和复拍，以及手机尺寸的候选 GLB 操作。

编队成员或部署数量变更后，运行 `node tools/model-resources.mjs` 同步模型与摄影编队清单。
