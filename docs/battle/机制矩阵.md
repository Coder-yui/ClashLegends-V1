# 2D 战斗机制矩阵

本表记录可运行的机制、旧规则的来源，以及修改规则时必须复验的交互。大厅中每个技能选项的内容来源见[旧版主动技能索引](旧版主动技能索引.md)。表中按行为验收，整张卡的其他被动和主动仍需逐项对照。

## 感知和单位行动

| 问题 | 规则 | 边界与代表场景 |
| --- | --- | --- |
| 视野与射程分别管什么 | 旧 `sight` 载入 `sight_range`，缺省 220。新定义显式提供 `sight` 与 `range`。以中心距离减去双方身体半径，负值记零 | 近战兵 180/32、远程兵 210/150、河蟹 200/32。刚好等于视野可发现，在视野内且射程外时追击 |
| 没有敌人或多个敌人时追谁 | 筛阵营、空地、建筑偏好、凝滞、隐身、来源保护。常规从视野中取最近合法对象，稳定处理同距。攻击锁定和嘲讽各有优先规则 | 无候选向同路公主塔推进，同路塔倒后推水晶。视野内的近敌可打断行军。出手前原目标失效可在射程内转火 |
| 抵近目标后做什么 | 行动可为近战打击、发射弹体、持续单目标输出、分轮多目标汲取、停步自疗或静止 | 普攻在出手点允许额外 20 距离。河蟹只找建筑，停下每秒自疗 30。龙王吐息受攻速影响。远古恐惧对一轮目标集合汲取，出圈断线，晚进圈等下一轮 |
| 怎样算一次命中 | 弹体可追踪、直线首碰、直线贯穿、往返、落点范围与多次弹跳。弹匣以一次出手计数 | 男枪一发六线、空匣换弹，致盲可让整次攻击落空。回程单独记录目标。射手死亡后已释放弹体继续 |
| 生命变化如何结算 | 记录来源、请求伤害、吸收、实际掉血和死亡；数值护盾按到期顺序吸收。按真实掉血计算汲取 | 护盾全吸收时汲取为零。一次敌对技能交付包含伤害和定身时，一层效果盾同时挡住二者 |

旧版依据见[单位决策](../../../ClashLegends/scripts/unit.gd)、[河蟹卡牌](../../../ClashLegends/scripts/data/cards/scuttle_crab.gd)、[来源与效果保护](../../../ClashLegends/scripts/battle/combat_interaction.gd)。

## 导航、接触和合法落点

| 行为 | 途中约束 | 终点、取消与回归 |
| --- | --- | --- |
| 地面与空中移动 | 地面走可通行走廊及桥面；飞行用空中层。带权 A* 提供路线，同层单位接触后可侧移、按质量分摊重叠修正 | 验证另图绕障、两只只找建筑的河蟹迎面相遇、不能被推动的凝滞单位。路径层保留旧原生夹具 |
| 放置与出生 | 部署先对格，按卡牌占地检查半场或倒塔开放区；法术可点河道。二次生成以身体做最近合法位置查询 | 建筑格占地与圆形碰撞半径分别配置。部署期可受击，出牌失败保留金币和手牌 |
| 穿越式外力与自主冲刺 | 途中可越地形，优先原终点，再试有限前延及缩短。途中新建筑会改变合法终点 | 实际停止时复核。定身仍可接受外力，自主冲刺会被定身、眩晕或冰冻打断，凝滞中断外力并恢复合法位置 |
| 普通击退 | 按质量缩放距离，每一步扫掠地形及同层身体，含双方同时移动时的相对碰撞 | 撞停后维持剩余行动锁。轻、重目标与单步高速撞人分别验收 |
| 拉取与瞬移 | 拉取优先施法者身前并查询可容纳目标的位置；瞬移一次提交新坐标 | 验证身前目标点、受阻回退、地图边缘、定身阻止自主瞬移 |

旧版依据见[移动接触模型](../../../ClashLegends/docs/BATTLE_CONTACT_MODEL.md)、[落点查询](../../../ClashLegends/scripts/battle/unit_landing_query.gd)、[有界冲刺](../../../ClashLegends/scripts/battle/bounded_dash_state.gd)。

## 技能交互和生命周期

| 维度 | 当前可执行规则 | 代表判例 |
| --- | --- | --- |
| 玩家意图 | 即发、选位置、选方向、选位置再选方向。位置与单位向量分别进入权威求解，形状支持圆、环、扇、有限宽矩形 | 点加方向是新版扩展。拒绝错误意图形状、零方向、非有限坐标、超距、非本方施法者；失败不花费技能 |
| 效果作用域 | 以形状和身体相交选目标，按敌我、状态和来源筛选。结界读取施法者当前中心，失去来源后回退出手时中心，法术卡以己方水晶为来源 | 玩家点进敌人结界不会把施法者移动进去。友方效果可穿过友方结界 |
| 打断和归属 | 即时效果、一次延迟、周期脉冲、跟随施法者或固定位置。归施法者所有的阶段可被冰冻、凝滞或死亡取消。释放后独立的效果走自己的时钟 | 同一技能在释放前一拍与释放后一拍受控，结果不同。河蟹死亡留下独立回复区 |
| 硬控与软控 | 定身阻止自主移动，沉默阻止新施法，眩晕／冰冻禁止自主行动，凝滞阻止新交互并保留占位。嘲讽关联具体来源。减速分别影响移速与攻速 | 同类硬控保留各来源，移除某一来源保留其他来源。河蟹谦卑的两个倍率各自参与计算，外力速度独立。男爵之力可以改变普通攻击伤害和移动或攻击倍率，与敌方减速分别到期 |
| 生成、变形和复生 | 部署、定期生产、建筑寿命、死亡生成、生命归零进替代形态、延迟复原。变形按配置保留当前生命、比例或回满 | 墓碑受控最多积一批，凝滞暂停自然衰减。冰鸟蛋继承实体身份，可被击杀，存活到孵化时恢复 |
| 全卡内容边界 | 逐技能复用上述规则，补充专属状态和判例 | 标记与引爆、连锁跳转、成长层数、接管、特殊追踪路线等仍按卡迁移。代表单位覆盖的行为见[机制用例](../../battle-core/tests/mechanisms.rs)，全部选项见[索引](旧版主动技能索引.md) |

## 经典模式与表现接口

| 归属 | 已实现 | 回归锚点 |
| --- | --- | --- |
| 玩家席位 | 八张独立牌、四张手牌、种子洗牌、按槽轮转、费用上限十、前两卡位绑定主动实例、费用与次数、按席位单调命令序号 | 重复命令、过期手牌、部署未完成的主动、双方手牌隔离 |
| 地图与赛制 | 地图给出塔、水晶、兵线点、半场及倒塔开放区。185 秒常规时间，平塔进入 120 秒加时；水晶、塔数差和超时共同决定终局 | 兵线前后排错开 0.5 秒、加时首波、同一步双水晶倒、加时平局 |
| 输出与重放 | 稳定实体 ID，快照含逻辑朝向、生命、行动序号和起始 Tick、弹体、区域及控制。语义事件含出手、命中、变形、生成、死亡。输入记录绑定版本、种子和卡组 | 双机器人无画面对局、两个浏览器读取同一终局、断线后刷新、相同输入回放比较双方状态 |
