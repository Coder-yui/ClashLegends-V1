# 普攻命中与弹体创建节点

每次起攻时，战斗核心根据形态、攻击轮次、强化状态、近远程和目标类型选定攻击段。近战在跨过出手节点的逻辑步处理接触，远程在该步创建弹体。弹体随后独立飞行和碰撞。一次攻击中途变速时，攻击时钟保留已积累的进度。被冻结而取消的前摇不会推进轮次。

[战斗时序](../../content/attack_timing.json)按单位、战斗形态、普攻类型和轮次记录前摇比例。红蓝共用同一条规则。核心据此决定何时结算，并把本次攻击的类型、轮次和进度发给客户端。[动作标记](../../content/attack_nodes.json)另按模型记录原版姿势和证据。客户端据此把本方模型的接触或离手姿势对齐到权威出手时刻。[导入器](../../tools/import_attack_nodes.py)可以用本机 LoL 原包和发布的 GLB 离线重新标定两份数据。

## 如何读一个节点

| 字段 | 含义 |
| --- | --- |
| `source` | 原包攻击条目、帧号和采用的帧率，或采用的攻击槽、动画事件、项目分段依据。分数保留小数帧 |
| `markerUs` | 以微秒表示的项目片段采样位置，工作台可以定位到这个姿势。带首帧保持或经过拆段的动作记录实际可采样的位置 |
| 战斗时序表中的整数 | 前摇占该段基础攻击窗口的百万分比。连续攻击以出手到出手为周期，下一击按自己的前摇提前起手 |

完整动作默认用源节点秒数除以战斗所用片长。潘森只采用原片前 0.9 秒；蛮王的动作在挥刀前烘焙了 0.4 秒保持；阿兹尔的攻击槽明确给出 1.6 秒周期中的 0.25 秒出手；峡谷先锋采用攻击槽给出的 0.5/2 比例，姿势定位到独立普攻条目的第 12 帧。已有起手、命中和收势片段的角色按实际剪辑衔接。玛尔扎哈两支普攻分别在原片 18/61 和 16/61 秒进入收势。提莫致盲使用的起手片段只有 0.30 秒，其原技能标记超过片长，项目在片尾切入收势。

核心以每步 1,000 个基础攻击时钟单位保存出手开销，随实际攻速推进，在第一个跨过节点的 20 Hz 逻辑步结算。快照发布攻击角色、段号、进度与预计释放步。浏览器只采样姿势；前摇途中得到减速时，从已经挥到的位置继续。素材未加载也能在同一逻辑步完成攻击。

## 卡牌信息中的前摇和后摇

前摇从本击起手到本击出手，后摇从本击出手到下一击起手。远程的分界点是弹体创建，弹体飞行时间可以与后摇重叠。连续攻击时，出手间隔由上一击决定。前摇相同的两击可以直接用攻击间隔减去前摇求后摇；轮次不同，则本击后摇等于本击出手间隔减去**下一击**的前摇。腕豪左右拳的前摇都是 0.30 秒，出手间隔交替为 0.60 秒和 1.40 秒，所以左右拳的后摇分别是 0.30 秒和 1.10 秒。

卡牌展示连续攻击、目标始终在射程内的估算时间，按百分之一秒显示。强化技能列出技能生效期间的数值，末击接回普通攻击时按下一击前摇衔接。实战以 0.05 秒为一步；变速、移动取消后摇、换弹、引导和等待回旋镖都会影响实际起手时间。重新导出备战资料后运行下方导入器，即可从当前战斗规则重新生成属性、被动和技能的时序。

## 已核对的范围

本轮核对 100 张目录卡中的 60 张自身具有离散普攻的卡，以及两侧兵线、建筑、衍生物、变身和强化变体。表内另有 20 张法术、6 张兵种编队，余下 14 张自身采用持续机制、独立事件或无离散普攻。下表说明这些牌进入哪条路径。

| 类别 | 对象与处理 |
| --- | --- |
| 法术 | 20 张法术自身不执行普通攻击。空投熊、虚空召唤生成的单位按实体配置起攻，镜像使用实际复制出的单位 |
| 编队 | 重装部队、近战兵小队、小兵分队、远程兵小队、炮车部队、攻城部队逐成员使用对应兵种的共用出手规则和本方模型 |
| 持续机制 | 龙王、草间人及其费德提克形态按持续攻击或汲取结算；两种河蟹按持续修复结算 |
| 独立事件 | 虚空兽和单体变体走牺牲跳跃。已复核原动画第 23 帧的 TurretDeath 事件，对应跳跃开始后第 16 个逻辑步 |
| 其他无独立普攻的建筑 | 德邦军旗、金币守卫、高地水晶、凛冬之柱、火药桶、女王巢穴、训练木桩、墓碑、兹若特传送门按各自技能、生产或受击规则运行。巢穴、墓碑等生成的攻击单位另计 |
| 系统对象 | 防御塔四个攻击条目均为 4.95 帧，发弹时塔体保持当前受损外观。主水晶、训练目标和凤凰蛋无普攻出手节点 |

### 证据的边界

- 剑魔普通三刀和被动分别读取 11、9、7.5、12 帧。大灭两种普通攻击各有第 12 帧的独立条目，大灭被动使用项目抬高后的同一被动动作。
- 艾希两种普攻各为第 9 帧。远程兵的原包离手标记为蓝方第 14.1 帧、红方第 14 帧；项目把双方的两种普攻都定在第 14 帧发弹，共用前摇占攻击窗口的 14/49。近战兵两种普攻均在第 11.8 帧命中，完整片段蓝方为 0.900 秒、红方为 0.933 秒，双方共用按蓝方片长标定的战斗前摇。炮车兵均在第 9 帧发弹，超级兵均在第 15 帧命中，太阳圆盘和防御塔均在第 4.95 帧对应的节点发弹。
- Map11 原包另有远程兵的 `BasicAttack_Frenzy` 条目，蓝方为第 7.05 帧，红方为第 7 帧。当前项目的远程兵使用 `BasicAttack` 和 `BasicAttack2` 两个槽位，攻速增减沿用这两个槽位的共用节点。
- 共享槽和借用动作在清单中保留来源。沙兵只有一个明确的普攻法术条目；琴女和约里克的第三种动作共用基础槽定位；贾克斯技能期间的挥击沿用基础普攻参考。复用同一个项目动作时可以复用同一节点。
- 灵魂触手采用动画图第 22 帧的拍地事件。藤蔓鞭击者第一击的原包省略了 castFrame，采用 spellCastTime，第二击有独立的 7.5 帧标记。皮克斯两种动作指向同一 ANM，角色攻击槽和原皮动画图均未给出可直接归属的离手帧，保留项目 0.40 秒基础前摇。璐璐 Spell1 的弹体条目属于施法者，不能直接归到皮克斯的翅膀动作上。
- WAD 中的动画和法术数据可以定位表现节点。原版服务器脚本的额外延迟、多段效果和碰撞需要独立证据。本表只定义本项目选用的普攻路径。

## 复验

在仓库根目录执行以下命令。重建或比对源数据需要本机素材库、wadtools 和 ritobin-tools。常规运行和动作采样测试使用仓库中的发布数据。

```sh
python3 tools/import_attack_nodes.py --check
cargo test --locked --workspace
node web/tests/attack-nodes.mjs
npm --prefix web run build
```

工作台的模型预览可以定位出手姿势。实战应同时检查宿主的 attackReleased、fired、projectileHit 或伤害事件，尤其是变速和离手前冻结两种情况。启用本地测试宿主后，`web/tests/battle-actions.mjs` 可复验双席位的手部发射、近战接触和重连。
