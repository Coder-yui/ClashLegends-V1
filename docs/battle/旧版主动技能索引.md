# 旧版主动技能索引

范围为当前大厅内容版本的 106 个技能选项，按旧卡牌声明的 52 个 kind 分组。一个 kind 可以包含多个机制，例如带回复的普攻强化还涉及命中、真实掉血和治疗。迁移时应按每个选项的具体描述建立场景，再核对旧执行器和测试。远程虚空鱼大军继承远程虚空鱼的技能定义。
