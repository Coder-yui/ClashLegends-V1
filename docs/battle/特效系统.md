# 战场原生特效

正式对局和开发工作台共用 Three.js 粒子播放器。当前版本从本机 `LOL_Asset_Source` 的 68 个 WAD 选取 278 个系统，包含 2,279 个发射器。源版本为 `16.19.8217343+branch.releases-16-19.content.release`。旧项目用于核对卡牌选材、技能阶段、挂点、阵营和玩法尺寸。网页包中的纹理、特效网格和粒子采样均来自原始 WAD。

## 在工作台核对

打开 `/play/workbench?view=effects`。选择对象后，菜单先列出与它关联的原生系统，其余系统也可独立选择。时间轴按秒定位，单步按钮每次推进一个战斗 Tick（50 毫秒）。发射器可逐层开关。「原生来源」显示实际 WAD 和 BIN 条目。依附蒙皮的层会加载当前对象的模型，没有单位模型的对象使用艾希作预览载体。实战页可切换高、低、关闭三档画质，并叠加宿主发布的区域和弹体几何。

| 对象 | 实战核对点 |
| --- | --- |
| 艾希 | 比较普攻与万箭齐发的松弦位置、飞行方向和命中。每支箭按自己的 ID 飞行，同组箭命中同一目标时沿用宿主的去重结果。 |
| 琴女 | W 光环按治疗周期从根节点播放。R 施法层留在模型根，音波从释放姿态的武器位置出发，保持高度。局部 Y 沿航向，Z 朝上。 |
| 终极闪光 | 蓝红两方的前向相反。光束使用 3,410 个源单位映射玩法的 800 距离，射程从落点起算。 |
| 费德提克 | 多条汲取线各自连接当前可见目标。走出范围、目标死亡或持续阶段中断时，依宿主状态移除。 |
| 天使 | 普攻剑与扩宽的攻击波各自使用服务器的行程，攻击波可继续越过首个目标。 |

[逐卡核对表](特效覆盖.md)覆盖 100 张卡牌和 106 个可选技能。表中记录来源关联，具体时间、亮度、附着层与原客户端的逐帧视觉验收仍需按卡进行。项目自定义卡可复用已有原生系统，例如通用恢复使用迦娜治疗层，男爵小兵强化使用虚空生物发光层。镜像跟随实际复制出的牌。

## 资源如何生成

`content/effect_recipes.json` 为每个系统指定 WAD、皮肤 BIN 条目以及采样时长和频率。构建工具在 WAD 中找到 `VfxSystemDefinitionData`，解析本地 BIN 引用，按固定种子离线求出每层的位置、方向、颜色、UV、出生时刻等数据。纹理从原生 TEX 解码，静态特效网格从 SCB 导出。资源以内容哈希命名，相同内容只保存一份。每个系统在 `content/effect_provenance.json` 中保留 BIN 块、条目哈希、解析树 SHA-256，以及纹理和网格的 WAD 路径、块号和 SHA-256。

常规运行使用已生成的资源。重新制作需要已安装前端依赖、Rust、wadtools、ltk-tex-utils 和项目环境的 .NET SCB 导出器。将 LeagueToolkit 的 ltk-manager（含子模块）检出到版本 `712ddd1ecf725b6fc45aff7e629ee63e8137f13e`，把下面的路径换成本地检出位置。默认素材目录为 `~/Downloads/LOL_Asset_Source`。

```sh
python3 tools/import_battle_effects.py --ltk /path/to/ltk-manager --work /tmp/clash-vfx-build
python3 tools/verify_battle_effects.py --source ~/Downloads/LOL_Asset_Source
node tools/effect-coverage.mjs --check
```

`--work` 可复用中间产物。`--source`、`--tools`、`--scb` 可覆盖本机路径。校验工具也可直接运行，离线检查发布文件、系统索引、逐层依赖和所有采样偏移。传入素材目录时还会重新提取并核对原包依赖。

## 时间、坐标和画质

客户端按宿主的 20 Hz Tick 和显示插值读取表现状态。一次性命中消费席位事件序号，持续光环、弹体、区域、攻击波和汲取目标取自可见快照。重建基线时清除旧实例和拖尾历史，按当下阶段恢复。导弹离场即停止产生新粒子，拖尾继续消散。源帧中的局部坐标只经过一次场地投影。屏幕折射层仅在高画质且当前帧可见时抓取场景。

按己方手牌、已出现单位和已公开事件异步加载。几何视图也可用作资源未就绪时的定位反馈。低画质减少密集层实例和尾迹分段并关闭折射。跟随权重取发射器的常量，运动层根据实际出生时的位姿恢复世界位置。原生系统采用固定时长采样，长时间持续效果循环使用后段采样。复杂自定义材质、形态专用蒙皮遮罩和地表投影仍有与 LoL 客户端的差异，预览中的独立网格与角色附着层需要分别检查。

## 验证

全部 278 套系统在浏览器工作台完成载入和出图检查，包含 6 套完全依附模型表面的系统。重新构建后索引和来源清单的 SHA-256 一致，另从原 WAD 重提并比对了 1,956 个纹理和网格依赖块。

本轮在 Apple M5、桌面 Chrome 的双人对局中检查了交替攻击、手部发射及重载后的基线。开发工作台验证了蓝红阵营琴女、终极闪光、群体汲取、控制层和逐发射器开关。移动回归使用桌面 Chrome 的 390 × 844、DPR 3 触屏模拟。
