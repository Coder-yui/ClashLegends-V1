# 战场原生特效

正式对局和开发工作台共用 Three.js 粒子播放器。当前版本从本机 `LOL_Asset_Source` 的 68 个 WAD 选取 291 个系统，包含 2,515 个发射器。源版本为 `16.19.8217343+branch.releases-16-19.content.release`。旧项目用于核对卡牌选材、技能阶段、挂点、阵营和玩法尺寸。网页包中的纹理、特效网格和粒子采样均来自原始 WAD。

## 在工作台核对

打开 `/play/workbench?view=effects`。选择对象后，菜单先列出与它关联的原生系统，其余系统也可独立选择。时间轴按秒定位，单步按钮每次推进一个战斗 Tick（50 毫秒）。发射器可逐层开关。「原生来源」显示实际 WAD 和 BIN 条目。依附蒙皮的层会加载当前对象的模型，没有单位模型的对象使用艾希作预览载体。实战页可切换高、低、关闭三档画质，并叠加宿主发布的区域和弹体几何。

| 对象 | 实战核对点 |
| --- | --- |
| 艾希 | 比较普攻与万箭齐发的松弦位置、飞行方向和命中。每支箭按自己的 ID 飞行，同组箭命中同一目标时沿用宿主的去重结果。 |
| 琴女 | W 光环按治疗周期从根节点播放。R 施法层留在模型根，音波从释放姿态的武器位置出发，保持高度。局部 Y 沿航向，Z 朝上。 |
| 终极闪光 | 蓝红两方的前向相反。光束使用 3,410 个源单位映射玩法的 800 距离，射程从落点起算。 |
| 费德提克 | 多条汲取线各自连接当前可见目标。走出范围、目标死亡或持续阶段中断时，依宿主状态移除。 |
| 天使 | 普攻剑与扩宽的攻击波各自使用服务器的行程，攻击波可继续越过首个目标。 |

[逐卡核对表](特效覆盖.md)覆盖 100 张卡牌和 106 个可选技能。[逐卡战斗实测](特效实测.md)列出 279 组场景的绘制结果、坐标、比例、时间和未触发阶段，并附黑边修正前后同帧对照。项目自定义卡可复用已有原生系统，例如通用恢复使用迦娜治疗层，男爵小兵强化使用虚空生物发光层。镜像跟随实际复制出的牌。

原版数据的普攻出手标记为 9 帧，W 主法术的施放标记为 7.5 帧。项目沿用旧版卡牌的 W 松弦姿态（原片 0.30 秒），技能动画总长 1 秒。宿主按 20 Hz 推进，配置的 0.16 秒出箭延迟在第 4 个 Tick 生效。实战进入技能动作混合 0.05 秒。工作台自由预览切换动作时交叉淡化 0.30 秒。暂停定位直接显示选定姿态。[艾希原皮模型查看器](https://modelviewer.lol/model-viewer?id=22000&lang=zh-CN)

冰霜射击的持续减速沿用项目通用减速表现。原皮资源表收录了 `Ashe_freeze`，当前素材包中 `AshePassiveSlow` 的定义只给出状态说明，未找到将两者直接关联的事件。

## 资源如何生成

`content/effect_recipes.json` 为每个系统指定 WAD、皮肤 BIN 条目以及采样时长和频率。构建工具在 WAD 中找到 `VfxSystemDefinitionData`，解析本地 BIN 引用，按固定种子离线求出每层的位置、方向、颜色、UV、出生时刻等数据。纹理从原生 TEX 解码，静态特效网格从 SCB 导出。资源以内容哈希命名，相同内容只保存一份。每个系统在 `content/effect_provenance.json` 中保留 BIN 块、条目哈希、解析树 SHA-256，以及纹理和网格的 WAD 路径、块号和 SHA-256。

常规运行使用已生成的资源。重新制作需要已安装前端依赖、Rust、wadtools、ltk-tex-utils 和项目环境的 .NET SCB 导出器。将 LeagueToolkit 的 ltk-manager（含子模块）检出到版本 `712ddd1ecf725b6fc45aff7e629ee63e8137f13e`，把下面的路径换成本地检出位置。默认素材目录为 `~/Downloads/LOL_Asset_Source`。

```sh
python3 tools/import_battle_effects.py --ltk /path/to/ltk-manager --work /tmp/clash-vfx-build
python3 tools/verify_battle_effects.py --source ~/Downloads/LOL_Asset_Source
python3 tools/verify_battle_effects.py --reference ../ClashLegends
node tools/effect-coverage.mjs --check
```

`--work` 可复用中间产物。`--source`、`--tools`、`--scb` 可覆盖本机路径。校验工具也可直接运行，离线检查发布文件、系统索引、逐层依赖和所有采样偏移。传入素材目录时还会重新提取并核对原包依赖。

## 地形和逐层深度

晴昼峡谷从项目的三维场景 `rift_arena.glb` 导出桥、河床、岩石和带透明裁切的植被。固定镜头和回放自由镜头都渲染这份网格。地形先写深度，单位、建筑和粒子随后的每个像素都可使用这个深度值。建筑地基按所在位置留孔。峡谷沿用固定镜头的烘焙颜色，自由镜头所见的背面也使用这份颜色。交错桥测试场使用自己的平面地形。独立模型观察台使用模型坐标系中的地面，河蟹死亡后续动作的入土过程由蒙皮与地面的相交自然产生。

从同一份场景重建网页地形可运行 `python3 tools/import_battle_terrain.py ../ClashLegends/assets/arena/rift_arena`。导出保留遮挡轮廓与树冠透明阈值。地形网格仅用于表现，通行、命中和落点仍由战斗核心计算。

在当前发布的 2,286 个原生发射器中，1,114 层关闭深度测试，189 层指定非零多边形深度偏移，10 层沿视线推拉，146 层通过与表面的距离淡入或淡出。552 层在地表阶段绘制，4 层沿地形投影。以下参数均来自各自的 WAD 发射器。

| 系统和层 | 原生参数如何影响画面 |
| --- | --- |
| 琴女 R · `bartrail`、`notetrail` | `bartrail` 在地表阶段关闭深度测试，`notetrail` 接受遮挡。 |
| 琴女 R · `Wave_ADD1` | 在地表阶段测试深度，并用 50 个源单位的距离做软粒子淡入。 |
| 奥拉夫 R · `FireGlow`、`Avatar` | `FireGlow` 关闭深度测试，`Avatar` 保留深度测试并使用 −1、−5 的多边形偏移。 |
| 厄运小姐 W · `Basic3` | 按 −50 个源单位沿视线拉近，换算时使用特效实例的缩放。 |

透明裁切层按原生阈值丢弃空白像素，只为通过阈值的像素写深度。折射按发射器要求分别取样单位绘制前和绘制后的场景，两阶段折射分别使用各自的颜色缓冲。地表投影从地形深度重建每个像素的位置，再按投影范围和高度衰减计算覆盖。

## 时间、坐标和画质

客户端按宿主的 20 Hz Tick 和显示插值读取表现状态。一次性命中消费席位事件序号，持续光环、弹体、区域、攻击波和汲取目标取自可见快照。重建基线时清除旧实例和拖尾历史，按当下阶段恢复。导弹离场即停止产生新粒子，拖尾继续消散。源帧中的局部坐标只经过一次场地投影。屏幕折射层仅在高画质且当前帧可见时抓取场景。

按己方手牌、已出现单位和已公开事件异步加载。几何视图也可用作资源未就绪时的定位反馈。低画质减少密集层实例和尾迹分段并关闭折射。跟随权重取发射器的常量，运动层根据实际出生时的位姿恢复世界位置。原生系统采用固定时长采样，持续效果按各自的预热、循环和停留窗口采样。固定尺度和重复时段集中在 `web/src/effect-calibration.ts`，法术半径与阶段绑定在 `web/src/effect-bindings.ts`。复杂自定义材质和形态专用蒙皮遮罩仍有与 LoL 客户端的差异，预览中的独立网格与角色附着层需要分别检查。

## 验证

首批 290 套系统在浏览器工作台完成载入和几何提交检查。282 套包含独立几何，8 套完全依附模型表面。使用导入器的原生 BIN 读取程序作为校验器的 --reader 参数后，从 WAD 重读核对了全部系统定义和 2,003 个依赖块，当时的发布清单共 1,910 个文件。艾希专项复核增加了万箭齐发的独立命中特效，当前清单共 1,911 个文件。

此前在 Apple M5、桌面 Chrome 的双人对局中检查了交替攻击、手部发射及重载后的基线。开发工作台验证了蓝红阵营琴女、终极闪光、群体汲取、控制层和逐发射器开关。移动回归使用桌面 Chrome 的 390 × 844、DPR 3 触屏模拟。

下面是接入三维地形深度前，同一段回放叠加定量齐射的桌面高画质基线。每四个单位配置一支循环飞行的箭。CPU 耗时指战场绘制回调，帧间隔包含浏览器调度。结果适用于热缓存和该测试场景。

| 32 | 300 | 3.9 ms | 17.8 ms |

## 复现组合表现检查

使用 `CLASH_EFFECT_FRAMES=/tmp/clash-fx-frames cargo test -p clash-lobby export_effect_stages -- --ignored` 导出 22 组战斗帧。运行 `node web/tests/effect-stages.mjs /tmp/clash-fx-frames /tmp/clash-fx-blue 0`，最后两个参数改为 `/tmp/clash-fx-red 1` 可用另一席位重绘。输出包括逐系统测量、挂点与阶段断言以及阶段截图。

在导入粒子系统后运行 `python3 tools/import_pantheon_arrival.py` 生成独立矛和双动画剪影。运行 `python3 tools/import_reksai_rocks.py --work <粒子导入器的工作目录>` 生成岩石原始骨架和逐粒子出生时钟。两份发布清单记录原 WAD 路径、块哈希与源文件摘要。
